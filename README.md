# Next Technologies website

Bilingual English/Arabic corporate website with light and dark themes.

## Preview

Run `python3 -m http.server 8000` from this folder, then open http://localhost:8000.
No build or package installation is required. An internet connection is needed for Google Fonts.

## Files

- `index.html`: page layout, styles, content and interactions.
- `assets/`: images extracted unchanged from the approved HTML export.
- `SOURCE.md`: source version and import notes.

## Editing

Create a branch, make changes, preview English and Arabic in both themes at desktop and mobile widths, and open a pull request for review before merging into `main`.

## Draft status

Contact details, founder portraits and registration fields still contain placeholders. The enquiry form is a preview and does not send messages. Privacy and terms links need final content before public launch. No automatic deployment is configured by this import.
